> 编制日期：2026-08-08

## 一、采购背景与目标

### 1.1 背景

Eregen 手环 Pro+ 版新增电化学检测模块，需配套自研试纸（血糖/尿酸）作为耗材。试纸采用 FAD-GDH 脱氢酶法，三电极设计，需通过 ODM 代工生产。

### 1.2 采购目标

| 目标 | 指标 |
|------|------|
| 试纸精度 | 血糖 ±0.5mmol/L，尿酸 ±15% |
| 测试时间 | ≤10秒 |
| 采血量 | 0.3~0.6μL |
| 有效期 | ≥12个月 |
| 成本目标 | ≤2元/条（量产50万条/年） |
| 注册目标 | 二类医疗器械注册证 |

---

## 二、试纸技术要求

### 2.1 电化学参数

| 参数 | 规格 |
|------|------|
| 电极类型 | 三电极（金工作电极 + 碳对电极 + Ag/AgCl参比） |
| 酶法 | FAD-GDH（脱氢酶） |
| 测量范围 | 血糖 1.1~33.3mmol/L，尿酸 60~900μmol/L |
| 工作电压 | +0.3V vs Ag/AgCl |
| 响应时间 | ≤10秒 |
| 温度范围 | 10~40°C（带温度补偿） |

### 2.2 微流控参数

| 参数 | 规格 |
|------|------|
| 进样方式 | 毛细作用，侧边加样 |
| 加样量 | 0.3~0.6μL |
| 通道深度 | 50~100μm |
| 填充时间 | ≤5秒 |

### 2.3 物理参数

| 参数 | 规格 |
|------|------|
| 试纸尺寸 | 自定义（申请专利，不与市售兼容） |
| 基材 | PET薄膜 0.1mm |
| 包装 | 铝箔袋 + 干燥剂 |
| 每盒数量 | 50条 |

## 四、采购流程

### 4.1 流程概览

```
需求确认 → 供应商寻源 → 资质审核 → 样品测试 → 商务谈判
    ↓
小批量试产 → 注册检验 → 批量采购 → 质量监控 → 供应商评估
```

### 4.2 阶段一：需求确认（1周）

- [ ] 完成试纸技术规格书
- [ ] 完成采购预算审批
- [ ] 确定年度需求量（建议首批10万条）

### 4.3 阶段二：供应商寻源（2周）

**潜在供应商列表：**

| 供应商 | 地址 | 主要产品 | 联系方式 |
|--------|------|---------|---------|
| 三诺生物 | 湖南长沙 | 血糖试纸 | 待对接 |
| 鱼跃医疗 | 江苏丹阳 | 血糖仪+试纸 | 待对接 |
| 九安医疗 | 天津 | 血糖仪+试纸 | 待对接 |
| 万孚生物 | 广东广州 | POCT试纸 | 待对接 |
| 基蛋生物 | 安徽合肥 | POCT试纸 | 待对接 |

**寻源方式：**
1. 行业展会（CMEF中国国际医疗器械博览会）
2. 供应商官网询价
3. 行业推荐引荐
4. ODM方案商对接

### 4.4 阶段三：资质审核（1周）

对意向供应商进行资质审核，审核内容包括：
- 营业执照
- 医疗器械生产许可证
- ISO 13485 证书
- 产品注册证
- 工厂审核报告

### 4.5 阶段四：样品测试（2周）

**测试项目：**

| 测试项 | 方法 | 标准 |
|--------|------|------|
| 精度测试 | 与 Reference Method 比对 | 血糖 MARD <10%，尿酸 <15% |
| 重复性测试 | 同一样本重复测试20次 | CV <5% |
| 线性范围测试 | 5个浓度梯度 | R² >0.98 |
| 干扰测试 | 常见干扰物（胆红素、维生素C等） | 偏差 <10% |
| 稳定性测试 | 加速稳定性（40°C/75%RH，3个月） | 有效期验证 |

### 4.6 阶段五：商务谈判（1周）

- [ ] 价格谈判（目标 ≤2元/条）
- [ ] 交货条款确认
- [ ] 质量保证协议签署
- [ ] 知识产权协议签署（试纸设计专利归属 Eregen）

### 4.7 阶段六：小批量试产（2周）

- 首批订单：5,000条
- 目的：验证量产能力、质量稳定性
- 验收标准：批次合格率 ≥98%

### 4.8 阶段七：注册检验（4-6周）

**注册检验流程：**

```
送检样品质检 → 型检报告 → 注册检验报告
```

**检测机构：**
- 河南省医疗器械检验所
- 北京市医疗器械检验所
- 广东省医疗器械监测研究所

**检验项目：**
- 电化学性能
- 生物相容性
- 微生物限度
- 有效期验证

### 4.9 阶段八：批量采购（持续）

**首年采购计划：**

| 季度 | 血糖试纸 | 尿酸试纸 | 组合装 |
|------|---------|---------|--------|
| Q1 | 2万条 | 1万条 | 0.5万条 |
| Q2 | 3万条 | 1.5万条 | 1万条 |
| Q3 | 5万条 | 2.5万条 | 2万条 |
| Q4 | 8万条 | 4万条 | 3万条 |

## 五、质量控制

### 5.1 来料检验

| 检验项 | 方法 | AQL |
|--------|------|-----|
| 外观检查 | 目视 | 1.0 |
| 尺寸测量 | 卡尺 | 1.5 |
| 电极阻抗 | 万用表 | 2.5 |
| 酶活性 | 比色法 | 4.0 |

### 5.2 过程控制

- 每批次保留样品（留样 ≥2年）
- 生产记录追溯至原材料批次
- 出厂检验报告随货同行

### 5.3 供应商绩效评估

| 指标 | 目标值 | 权重 |
|------|--------|------|
| 批次合格率 | ≥98% | 40% |
| 交货准时率 | ≥95% | 25% |
| 价格竞争力 | 行业均价 | 15% |
| 技术支持响应 | 24小时内 | 10% |
| 质量投诉率 | ≤1% | 10% |

## 六、风险管理

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 供应商产能不足 | 交付延迟 | 开发2-3家备选供应商 |
| 试纸精度不达标 | 用户体验差 | 明确技术规格，严格样品测试 |
| 注册检验失败 | 上市延迟 | 提前与检测机构沟通，准备充分 |
| 原材料价格上涨 | 成本增加 | 签订年度价格锁定协议 |
| 知识产权纠纷 | 法律风险 | 试纸设计专利提前申请 |
