## 三、并行规则

1. **同一时间只允许一个批次内任务并行** — 避免跨批次耦合
2. **固件与云平台可并行** — 通过协议文档约定接口，不阻塞
3. **UI 原型必须先于 Flutter/Vue 编码** — 未确认原型不写代码
4. **每个任务完成后立即验证** — 编译通过 + 单元测试 + 集成测试
5. **任务打钩标准** — 代码提交 + 测试通过 + 文档更新
