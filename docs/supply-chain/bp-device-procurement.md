## 一、采购背景与目标

### 1.1 背景

Eregen 手环 Pro+ 版通过 BLE 5.3 连接外置上臂式血压计配件，实现血压数据的自动同步。该配件为独立硬件产品，需采购或定制开发。

### 1.2 采购目标

| 目标 | 指标 |
|------|------|
| 测量原理 | 示波法（医疗级标准） |
| 测量范围 | 压力 0~280mmHg，脉搏 40~180次/分 |
| 精度 | 压力 ±3mmHg，脉搏 ±5% |
| 连接方式 | BLE 5.3 |
| 供电方式 | 充电式（USB-C） |
| 成本目标 | ≤150元/台（量产） |
| 注册目标 | 二类医疗器械注册证 |

## 三、采购方式选择

### 方案A：成品采购 + 定制固件（推荐）

**优点：**
- 开发周期短（4-6周）
- 成本可控（批量采购价）
- 质量稳定（成熟产品）

**缺点：**
- 需改造 BLE 协议
- 品牌定制受限制

**适用：** 快速上市验证阶段

### 方案B：ODM 定制开发

**优点：**
- 完全自主可控
- 专利保护完整
- 品牌差异化强

**缺点：**
- 开发周期长（12-16周）
- 模具成本高（20-50万元）
- 风险较高

**适用：** 量产阶段

### 建议路径

```
Phase 1（快速验证）：方案A — 成品采购 + 协议改造
    ↓
Phase 2（量产准备）：方案B — ODM 定制开发
```

## 五、采购流程

### 5.1 流程概览

```
需求确认 → 供应商寻源 → 样品测试 → 技术对接 → 商务谈判
    ↓
小批量采购 → 协议改造测试 → 批量采购 → 质量监控
```

### 5.2 阶段一：需求确认（1周）

- [ ] 完成产品规格书
- [ ] 确定采购数量（首批 500台）
- [ ] 预算审批通过

### 5.3 阶段二：供应商寻源（2周）

**寻源渠道：**
1. 医疗器械展会（CMEF）
2. 供应商官网询价
3. 行业协会推荐
4. ODM方案商对接

### 5.4 阶段三：样品测试（2周）

**测试项目：**

| 测试项 | 方法 | 标准 |
|--------|------|------|
| 血压精度 | 与水银血压计比对（n≥30） | 差异 ≤5mmHg |
| 脉搏精度 | 与心电图比对 | 差异 ≤5% |
| BLE连接 | 与手环Pro+配对测试 | 连接成功率 ≥95% |
| 数据传输 | 数据同步测试 | 完整性 100% |
| 续航测试 | 充满电后连续使用 | ≥30天 |
| 耐久性 | 袖带充放气循环 | ≥10,000次无故障 |

### 5.5 阶段四：技术对接（1周）

**需确认事项：**
- BLE 协议定制可行性
- 固件升级方式（OTA or USB）
- 数据格式对接
- API 接口开放程度

### 5.6 阶段五：商务谈判（1周）

**谈判要点：**
- 单价目标：≤150元/台（500台）
- MOQ：500台起
- 交货期：30天内
- 付款方式：30%预付 + 70%交货
- 质保期：2年
- 品牌定制：LOGO丝印、包装定制

### 5.7 阶段六：小批量采购（2周）

- 首批订单：500台
- 用途：用户测试、注册检验样机
- 验收标准：批次合格率 ≥98%

## 六、注册与合规

### 6.1 注册路径

**方案A（成品采购）：**
- 使用供应商已有注册证
- Eregen 作为经销商备案
- 注册周期：1-2个月

- 独立注册申请
- 注册周期：12-18个月

## 八、风险管理

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| BLE协议不兼容 | 数据无法同步 | 提前技术对接，确认协议定制可行性 |
| 精度不达标 | 用户体验差 | 严格样品测试，明确验收标准 |
| 注册证过期 | 销售受阻 | 提前确认注册证有效期，续约协议 |
| 供应商断供 | 交付风险 | 开发2家备选供应商 |
| 成本超支 | 利润压缩 | 商务谈判锁定价格，签订年度协议 |
