# 家属APP v2.1 视觉升级设计

> 编制日期：2026-07-26
> 状态：已批准
> 对应子项目：家属APP (Flutter)
> 设计原则：浅色极简科技风，零业务变更

---

## 1. 设计目标

将家属APP所有页面的视觉风格统一为**浅色极简科技风**，在保持现有业务逻辑、API调用、状态管理、WebSocket实时推送、Hive离线缓存**完全不变**的前提下，仅改造UI渲染层。

核心改进点：
- 首页信息层级精简（健康图表横向切换替代纵向堆叠）
- 全页面视觉一致性（统一卡片样式、间距系统、色彩语义）
- 空状态/错误状态友好化
- 组件拆分提升可维护性（大Widget拆小组件）

## 2. 设计令牌（Design Tokens）

### 2.1 色彩体系

```
背景色:
  scaffold:    #F8FAFC  — 浅灰底色，清爽干净
  card:        #FFFFFF  — 白色卡片
  cardAlt:     #F8FAFC  — 次级卡片/选中态

主色系（深蓝）:
  primary:     #1B3A5C  — 标题栏、active态
  primaryMid:  #2D5F8A  — 次要强调
  primaryLight:#5B8DB8  — 链接、辅助文字
  primaryBg:   #EEF4FA  — 标签背景

强调色（健康绿）:
  accent:      #22C55E  — 在线状态、正常指标
  accentMid:   #4ADE80  — 图表渐变

状态色:
  normal:      #22C55E  — 正常
  warning:     #F59E0B  — 警告
  danger:      #EF4444  — 危险/SOS
  info:        #1B3A5C  — 信息

文字色:
  primary:     #0F172A  — 标题、主要数据
  secondary:   #475569  — 描述文字
  muted:       #94A3B8  — 次要信息、时间戳
```

### 2.2 间距系统

```
主间距:  16px（页面边距、卡片间距）
次间距:   8px（卡片内元素间距）
微间距:   4px（图标与文字间距）
紧凑:     2px（标签内间距）
```

### 2.3 圆角系统

```
cardRadius:     12px  — 标准卡片
cardRadiusLg:   14px  — 告警项、列表项
cardRadiusXl:   18px  — 英雄卡片、重要卡片
pillRadius:    9999px — 胶囊按钮、筛选标签
```

### 2.4 阴影系统


## 3. 页面级设计

### 3.1 首页 (HomePage)

**布局结构（自上而下）：**

```
┌─────────────────────────────────┐
│  [头像] 爷爷 张三丰    [切换 ▼] │ ← 英雄卡片（薄荷绿渐变）
│  ♥72  ◉98  👟3.5k  🔋85        │ ← 四宫格健康指标
├─────────────────────────────────┤
│  🚨 SOS紧急呼叫横幅（仅待处理时）│ ← 红色渐变 + 脉冲动画
├─────────────────────────────────┤
│                                 │
│        [地图定位区域]            │ ← 170px高，含电子围栏
│                                 │
├─────────────────────────────────┤
│  ⚡ 快捷操作                    │
│  [健康] [告警] [用药] [福利]    │ ← 4列网格，毛玻璃卡片
├─────────────────────────────────┤
│  📊 健康趋势    [查看全部 →]    │
│  ┌──────┬──────┬──────┐         │ ← 横向Tab切换
│  │ 心率 │ 血氧 │ 步数 │         │
│  │ [图表]          │         │
│  └──────┴──────┴──────┘         │
├─────────────────────────────────┤
│  🚨 最近告警      [查看全部 →]  │
│  [SOS紧急按钮触发    3分钟前 ›] │
│  [电子围栏越界       25分钟前 ›]│
│  [心率持续偏高       45分钟前 ›]│
└─────────────────────────────────┘
```

**关键改动：**
- 健康趋势从两个纵向堆叠的图表改为**横向Tab切换**（心率/血氧/步数），一次只显示一个图表
- 图表高度从80px压缩到60px，减少纵向空间占用
- 快捷操作从GridView改为带图标的玻璃卡片

**组件拆分：**
```
HomePage
├── HeroCardWidget          # 老人状态 + 健康指标四宫格
├── SOSBannerWidget         # 紧急SOS横幅（条件显示）
├── MapSection              # 地图定位（已有，保持不变）
├── QuickActionsGrid        # 4列快捷入口
├── HealthTrendTab          # 横向Tab + 单图表
│   ├── TabSelector         # 心率/血氧/步数 tab
│   └── ChartCard           # 单个指标图表
└── RecentAlertsList        # 最近告警（已有，保持不变）
```

## 5. 空状态/错误状态

所有页面统一空状态模板：

```
┌─────────────────────────┐
│                         │
│       [大图标]          │  ← 48px muted色图标
│                         │
│    "暂无告警"           │  ← 15px secondary色
│   "一切正常，继续加油"   │  ← 12px muted色
│                         │
│    [  刷新重试  ]       │  ← 120px宽 outline按钮
│                         │
└─────────────────────────┘
```

各页面文案：
- 首页：无（不展示空状态）
- 健康页："暂无健康数据" / "设备未连接或尚未采集数据"
- 告警页："暂无告警" / "一切正常，继续加油"
- 用药页："今日用药已完成" / "所有药物已服用"
- 福利页："暂无补助记录" / "符合条件的补助将在此展示"

网络错误统一SnackBar提示："网络连接失败，请检查网络设置" + 自动重试按钮
